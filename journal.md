# SwarmTrace — Development Journal

## Project Overview
SwarmTrace is a "pytest for AI agents" — an observability platform for LLM multi-agent swarms. Built for the AMD Hackathon, it provides tracing, debugging, token budgeting, tool attention (ISO scoring), web scraping traces, and regression detection. Two frontends: a TanStack Start dev-server and a Next.js 16 dashboard (frontend-next). Backend is Python/FastAPI with SQLite storage.
